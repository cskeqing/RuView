可靠性分析

基于仓库内可验证证据（基准指标、实现方式、数据规模）的评级
总体规律：可靠性与「信号物理强度」和「任务粒度」负相关。 二值 / 粗粒度任务（存在、有无、动/静）对应 CSI 幅度能量级变化——物理信号最强，可靠性最高； 连续 / 细粒度任务（关键点坐标、部位分割、身份）要求从微弱散射差异中恢复高维结构，可靠性最低。 难度自左列 L1 到 L5 递增，可靠性总体随之递减。

高可靠性

可放心用于演示 / 产品
存在检测 — 预训练编码器 82.3%（held-out temporal-triplet）、count_v1 权重在库、固件 DSP 自适应阈值，三重实现互相印证。
粗粒度活动识别 — 15 维特征 + Mahalanobis + 逻辑回归，统计方法鲁棒，支持 JSON 热加载按房间自适应。
0/1 人数检测 — count_v1 实际按 0/1 两分类训练，该粒度下可靠。
房间校准（LoRA） — 作为增强手段实测精度 11%→73%（ADR-150）。

中可靠性

可用，但需限定条件
静息生命体征 — IIR 带通（呼吸 0.1–0.5 Hz / 心率 0.8–2.0 Hz）原理成熟；运动干扰下下降；非临床级。
跌倒检测 — 相位加速度阈值规则；存在误报/漏报风险（宠物、物体坠落）。
穿墙运动存在 — 多频基线变化检测；运动存在可靠，精确定位不可靠。
睡眠监测 — 规则 + AHI 指数，静息卧室环境有利；非临床筛查级。

低可靠性

研究阶段，慎用
细粒度姿态（17 关键点） — 库内 pose_v1 真实基准仅 PCK@50=18.5%（单房间小数据）；MM-Fi 82.69% 为公开基准且权重外部托管，新环境未经 LoRA 校准则精度崩塌。
密集姿态 DensePose — 研究/原型级，库内无训练权重，复现的 CMU 论文本身受质疑。
身份识别 — RF Encoder Identity 头为研究阶段，跨环境泛化未验证。
世界模型 OccWorld — Candle 版属原型，Python 重训练依赖外部环境。
材料识别 / 救援 — 训练数据有限，救援场景未经实战验证。
诚实性重申：pose_v1 的库内基准 PCK@50=18.5% 与 MM-Fi Transformer 的 torso-PCK@20=82.69% 来自不同模型、不同数据集，不可混用。结论：姿态估计在公开数据集上表现强， 但在真实新房间中未经 LoRA 校准则不可靠（11%→73% 即校准前后差距）。

说明

图例

已实现绿色 — 代码已落地，可直接构建 / 运行。
原型橙色 — 实验性、研究原型或示例原型，未达生产状态。
仅参考灰色 — 仅作论文复现 / 架构参考，无权重、未集成。
权重外部托管蓝色 — 模型权重托管于 HuggingFace，不在仓库内。
◇ 非学习琥珀色虚线标记 ◇ — 表示非神经网络方案：DSP 信号处理、阈值/规则检测、图算法（如最小割、K-means）或物理仿真，与学习型模型明确区分。
难度色阶 L1–L5 — 绿（L1 简单）经黄、橙渐变至红（L5 困难），按任务物理可行性从易到难排序；「浏览器端感知」为部署层能力，未评级。
高可靠性徽章 — 高=绿（可放心使用）；中高 / 中=黄（可用但需限定条件）；低中 / 低=红（研究阶段，慎用）。评级依据见「03 / 可靠性分析」。

诚实性声明

基准数据不可混用：库内 pose_v1 的真实基准为 PCK@50 = 18.5%， 而 MM-Fi Transformer PoseNet 的 torso-PCK@20 = 82.69% —— 两者为不同模型、不同数据集上的结果，不可互相替代或混合引用。

权重托管位置：旗舰模型权重托管于 HuggingFace，仓库内不含二进制权重： ruvnet/wifi-densepose-mmfi-pose、ruvnet/wifi-densepose-pretrained。

数据口径：本页所有对应关系、状态与路径均来自全仓库调研确认的事实，未做推测性补充。
